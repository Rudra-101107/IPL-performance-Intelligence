04 / Insights to investigate
Data interpretation: The source combines ball-by-ball rows with match-info metadata. This dashboard analyzes only ball-by-ball records. Season totals are not directly comparable if seasons are incomplete. Legal-delivery logic excludes wides and no-balls, but player-specific balls faced and official bowler-conceded runs require more detailed cricket rules (for example, byes and leg-byes are not charged to the bowler). This is a descriptive analytics view, not a measure of causation.
